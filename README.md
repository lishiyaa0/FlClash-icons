# FlClash 图标库

个人 FlClash / Mihomo 策略组图标，供 `icon:` 字段引用。

- **图标数量**：349
- **索引文件**：`icons.json`（含每个图标的名称、地址，以及本配置中的用途）
- **来源**：主要来自 [Koolson/Qure](https://github.com/Koolson/Qure) 的 `IconSet/Color`，另有 [bgpeer/icons](https://github.com/bgpeer/icons) 的 `claude_1.png`、`douyin_1.png`（已由 WebP 转为 PNG）

## 用法

```yaml
icon: "https://raw.githubusercontent.com/lishiyaa0/FlClash-icons/main/color/Google.png"
```

国内网络可加 gh-proxy 前缀：

```yaml
icon: "https://gh-proxy.com/https://raw.githubusercontent.com/lishiyaa0/FlClash-icons/main/color/Google.png"
```

或使用 jsDelivr（有缓存延迟）：

```yaml
icon: "https://cdn.jsdelivr.net/gh/lishiyaa0/FlClash-icons@main/color/Google.png"
```
